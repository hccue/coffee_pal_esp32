# Coffee Pal

A small animated mug for the Waveshare ESP32-S3-Touch-LCD-1.47 that counts coffees and milk froths, and tells you when to empty the drip tray before it overflows.

## Flashing the board

Needs [PlatformIO](https://platformio.org/) (`pipx install platformio`).

1. Plug the board in with a USB‑C cable that carries data (many charge-only cables don't), directly rather than through a hub. It should appear as `/dev/cu.usbmodem…` on macOS (`pio device list` shows it).
2. From this folder, run:

   ```sh
   pio run -t upload
   ```

   On a Mac where `pio` isn't on the PATH (PlatformIO's installer puts it in `~/.platformio`), run this instead:

   ```sh
   ~/.platformio/penv/bin/pio run -t upload
   ```

   The first run downloads the ESP32 toolchain, so it takes a few minutes. After that it finds the port, builds and flashes.

To use plain `pio` instead, add `export PATH="$HOME/.platformio/penv/bin:$PATH"` to `~/.zshrc`.

If the board doesn't show up or the upload can't connect, hold **BOOT**, tap **RESET**, release **BOOT**, and upload again. Tap **RESET** when it finishes.

## Using it

| Tap | What happens |
| --- | --- |
| **+ Coffee** | Adds a coffee. |
| **+ Froth** | Adds a froth. |
| **Reset** | Asks **Sure?** for 3 seconds. Tap again to clear the counts. |
| **Emptied** | Replaces Reset when the tray is full. One tap clears the counts. |

A small dot in the corner of **+ Coffee** or **+ Froth** means that button was pressed in the last 5 minutes. It fades as the time passes, so you can see whether the drink you just made was already counted.

The bar under the mug is the tray, with one notch per drink. It turns amber when the tray is almost full. When the tray is full, the screen pulses red and shows "EMPTY THE TRAY!" until you tap **Emptied**.

Counts survive a power cut. After 10 idle minutes the mug naps and the screen dims, unless the tray is full. A button tap wakes it and still counts.

## Changing the tray rules

Edit `src/config.h` and flash again.

```c
#define COFFEE_UNITS 1
#define FROTH_UNITS 2
#define TRAY_CAPACITY_UNITS 12
#define TRAY_WARN_REMAINING_UNITS 2
```

Each drink adds its units, and the tray is full at the capacity. A froth puts twice as much water in the tray as a coffee, so the defaults give 12 coffees alone, 6 froths alone, or 4 coffees + 4 froths. `FLIP_SCREEN` in the same file turns the picture upside down.

## Testing

Tray rules and touch behaviour, plus one image per screen, with no hardware:

```sh
clang++ -std=c++17 -O2 -Isrc test/preview.cpp src/ui.cpp -o /tmp/preview && /tmp/preview /tmp
```

Against a connected board (this clears its counts). It needs pyserial, which PlatformIO's own Python already has. The expected counts come from `src/config.h`, so flash from the same checkout first:

```sh
python3 tools/device_check.py <serial port> <folder for screenshots>
```

The serial port is something like `/dev/cu.usbmodem101` on macOS, `/dev/ttyACM0` on Linux or `COM3` on Windows. `pio device list` shows it.

The board also takes single-letter commands over USB serial: `c`, `f` and `r` press the buttons, `i` prints status and timing, and `s` dumps the current frame.

## Files

- `src/config.h`: tray rules and device settings
- `src/tray.h`: what the counts mean for the tray
- `src/ui.cpp`: layout, animation and touch behaviour
- `src/gfx.h`: anti-aliased drawing
- `src/main.cpp`: display, touch, backlight and saved counts
- `src/font_data.h`: generated by `tools/make_font.py` from `assets/Nunito.ttf` (SIL Open Font License)
